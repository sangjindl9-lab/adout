# 알려진 제한사항 및 미구현 기능

이 문서는 **검증하지 못했거나 구현하지 않은 항목**을 숨기지 않고 기록합니다.

## 1. 이번 빌드에서 검증하지 못한 것

| 항목 | 상태 | 사유 / 대안 |
| --- | --- | --- |
| 실기기 VPN 연결 및 DNS 차단 | **미검증** | CI/개발 환경에 Android 기기·에뮬레이터가 없습니다. VpnService 코드와 TUN 패킷 처리기는 순수 바이트 단위 단위 테스트로만 검증했습니다(DnsTunHandlerTest 8건). |
| VPN 연결 상태에서 정상 인터넷 유지 | **미검증** | 상동. 설계상 DNS 이외 트래픽은 라우팅하지 않아 영향이 없어야 하나 실기기 확인 필요. |
| DoH/DoT 실제 통신 | **미검증** | 구현은 있으나(HTTPS/TLS 소켓 + protect) 외부 DNS 서버와의 실제 왕복은 테스트하지 않았습니다. |
| Wi-Fi ↔ 모바일 전환, Private DNS 환경 | **미검증** | 실기기 테스트 필요. |
| 설치 앱 검사 전체 실행 | **부분 검증** | PackageManager 수집 로직은 구현했으나 Robolectric 환경에서는 실제 앱 목록이 없어 실행 검증을 못 했습니다. APK 분석 경로는 픽스처로 검증. |
| Google Play 심사 통과 | 해당 없음 | 제출하지 않았습니다. |
| AAB 업로드/내부 테스트 트랙 | 해당 없음 | 콘솔 작업 미수행. |

## 2. 의도적으로 대체 구현한 것

| 원래 계획 | 실제 구현 | 이유 |
| --- | --- | --- |
| **AdGuard DNSLib (C++/Rust) 네이티브** | 순수 Kotlin DNS 엔진(`core/dns`) | NDK/Rust 크로스 컴파일과 JNI 안정성 검증을 이번 작업에서 완료하지 못했습니다. DNS 와이어 포맷 파싱/생성, AdGuard·hosts 규칙 파싱, 필터 우선순위, 응답 캐시를 직접 구현하고 단위 테스트로 검증했습니다. JNI 연동 지점은 `DnsFilterEngine` 인터페이스로 분리되어 있어, 향후 `DnsLibs` 를 붙일 때 이 클래스만 교체하면 됩니다. |
| **YARA-X (Rust) 네이티브** | 자체 YARA 부분집합 엔진(`core/yara`) | 상동. 지원 문법: 문자열/hex(와일드카드)/ascii·wide·nocase·fullword, 조건 `all|any|N of them`, `and/or/not`, 괄호. 정규식 문자열·filesize·`#count`·for 문 등은 **미지원**이며 컴파일 오류로 보고합니다. |
| **Androguard 서버 심층 분석** | 미포함 | 서버 인프라가 없습니다. 확장 지점만 설계. |
| **ClamAV 보조 검사** | 미포함 | 상동. |

## 3. 기능적 한계 (설계상)

- **DNS 전용 VPN**: 0.0.0.0/0 을 라우팅하지 않습니다. 따라서
  - DoH/DoT 를 사용하는 앱(예: 일부 브라우저의 내장 DoH)의 DNS 는 잡지 못합니다.
  - 앱 내부에 포함된 광고, HTTPS 영상 광고는 제거되지 않습니다.
  - TCP DNS(RFC 7766)는 처리하지 않습니다(UDP/53 만).
  - 주요 공용 리졸버(8.8.8.8 등)로 가는 질의를 잡기 위해 /32 경로를 추가했지만,
    앱이 임의의 DNS 서버를 쓰면 우회될 수 있습니다.
- **차단 통계**: DNS 요청 차단 건수이며 "광고 제거 건수"가 아닙니다(UI 에 명시).
- **해시 DB**: 실제 악성 해시 데이터가 없어 현재 DB 는 비어 있고, 초기 필터의 피싱/악성
  도메인 목록은 **예시 데이터(isTestData=true)** 입니다. 운영 탐지 데이터는 서명된
  업데이트로 공급해야 합니다.
- **APK 서명 검증**: 인증서 지문을 읽어 표시할 뿐, 서명의 유효성(무결성)을 암호학적으로
  검증하지는 않습니다. v2/v3 블록에서 인증서를 추출해 SHA-256 을 표시합니다.
- **설치 앱 파일 접근**: Android 버전/제조사에 따라 다른 앱의 APK 에 접근할 수 없습니다.
  이 경우 메타데이터(패키지·권한·서명 지문)만 검사하며 결과에 표시합니다.
- **오탐 완화**: 시스템 앱과 잘 알려진 접두사(`com.google.`, `com.kakao.` 등)에 대해
  신뢰도·심각도를 낮추는 휴리스틱을 적용했습니다. 완벽한 판별은 아니며, 사용자 허용/차단
  목록과 오탐 신고 경로를 제공합니다.
- **언어**: 5개 언어 리소스를 제공하지만, 탐지 근거의 기술 문자열(권한명·도메인·파일명)은
  번역하지 않고 원문을 유지합니다(감사 가능성 우선).

## 4. 개인정보/정책 관련 남은 일

- `support_email` 이 `support@eum-security.example` 로 되어 있습니다. 배포 전 실제 주소로 교체해야
  오탐 신고 메일이 동작합니다.
- 개인정보 처리방침의 사업자 정보·문의처 확정 필요.
- Play Console 의 VPN/QUERY_ALL_PACKAGES 신고 문구 입력 필요(문구는 docs 에 준비됨).

## 5. 테스트 공백

- 계측(instrumented) 테스트(`androidTest`)는 작성하지 않았습니다(기기 필요).
- UI 스냅샷/Compose UI 테스트 없음.
- 성능 측정(앱 시작·DNS 지연·배터리)은 실기기에서 수행하지 못했습니다.
- 배터리 최적화·장시간 VPN 안정성 미검증.

## 6. 향후 확장(설계만)

앱별 네트워크 사용량, 앱별 통신 차단, 의심 링크 검사, PDF 보고서, 가족 기기 관리,
보안 DB 관리자 웹, 기업용 관리, 클라우드 심층 분석, 상용 위협 인텔리전스 연동.
