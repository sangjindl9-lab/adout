// EUM SECURITY PRO — 개인정보 처리방침 (초안)

최종 수정: 2026-11-22
시행일: 정식 배포일

> 초안입니다. 정식 배포 전에 사업자 정보, 문의처, 보관 기간을 확정해야 합니다.

## 1. 수집·처리하는 정보

EUM SECURITY PRO(이하 "앱")는 다음 정보를 **기기 안에서만** 처리합니다.

| 구분 | 내용 | 저장 위치 | 외부 전송 |
| --- | --- | --- | --- |
| 광고 차단 | DNS 질의 도메인, 차단 시각, 차단 범주 | 기기 내부 Room DB | 없음 (사용자가 켠 DoH/DoT 업스트림 질의는 예외) |
| 악성코드 검사 | 패키지명, 파일 경로, SHA-256, 탐지 근거 | 기기 내부 Room DB | 없음 |
| 설정 | 차단 스위치, DNS 모드, 언어, 테마 | 기기 내부 DataStore | 없음 |
| 설치 앱 목록 | 앱 이름/패키지/권한/서명 지문 | 기기 내부 Room DB | 없음 |

서버 심층 분석(Androguard/ClamAV)은 이 버전에 포함되지 않았습니다. 포함될 경우 파일별
명시적 동의를 받고, 업로드 전에 전송 대상·보관 기간·목적을 화면에 표시합니다.

## 2. VPN(DNS) 처리

- Android `VpnService` 로 **DNS 질의만** 가상 DNS 서버로 보내 확인합니다.
- 일반 인터넷 트래픽은 VPN 을 통과하지 않으며 앱이 읽거나 저장하지 않습니다.
- HTTPS 콘텐츠를 복호화하지 않습니다.
- DNS 질의는 기본적으로 기기 시스템 DNS 로 전달되며, DoH/DoT 선택 시 해당 제공자에게
  암호화되어 전달됩니다.
- VPN 은 사용자가 켜고 끄며, 사용자가 중지한 VPN 을 앱이 임의로 다시 시작하지 않습니다.

## 3. 권한 사용 목적

| 권한 | 목적 |
| --- | --- |
| `INTERNET`, `ACCESS_NETWORK_STATE` | DNS 업스트림 전달, 보안 DB 업데이트 |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE` | 광고 차단 VPN 상시 유지 |
| `POST_NOTIFICATIONS` | VPN 상태·검사 결과 알림 |
| `QUERY_ALL_PACKAGES` | 설치 앱 검사(핵심 기능) |

APK 파일 선택은 Storage Access Framework 를 사용하며 저장소 전체 접근 권한을 요청하지 않습니다.

## 4. 보관 및 삭제

- 차단 기록: 기본 30일(설정 1~365일), 이후 자동 삭제
- 검사 결과: 설정의 "검사·차단 기록 삭제" 로 즉시 삭제
- 앱 삭제 시 기기 내부 데이터도 삭제

## 5. 제3자 제공

사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. 다음 경우에만 네트워크 요청이 발생합니다.

- 보안 DB/필터 업데이트: 설정된 HTTPS 업데이트 서버
- DoH/DoT 사용: 사용자가 선택한 DNS 제공자

## 6. 아동의 개인정보

만 14세 미만 아동을 대상으로 하지 않으며 아동의 개인정보를 별도 수집하지 않습니다.
