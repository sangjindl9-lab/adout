## 1. 수집하는 정보와 처리 목적

EUM SECURITY PRO(이하 "앱")는 다음 정보를 **기기 안에서만** 처리합니다.

| 구분 | 내용 | 저장 위치 | 외부 전송 |
| --- | --- | --- | --- |
| 광고 차단 | DNS 질의 도메인, 차단 시각, 차단 범주 | 기기 내부 Room DB | 전송하지 않음(사용자가 켠 DoH/DoT 업스트림 질의 제외) |
| 악성코드 검사 | 검사 대상 패키지명, 파일 경로, SHA-256, 탐지 근거 | 기기 내부 Room DB | 전송하지 않음 |
| 설정 | 차단 스위치, DNS 모드, 언어, 테마 | 기기 내부 DataStore | 전송하지 않음 |
| 설치 앱 목록 | 앱 이름/패키지/권한/서명 지문 | 기기 내부 Room DB | 전송하지 않음 |

서버 분석(Androguard/ClamAV)은 이 버전에 포함되지 않았습니다. 포함될 경우 사용자가
파일별로 명시적으로 동의한 경우에만 업로드하며, 업로드 전에 전송 대상·보관 기간·목적을
화면에 표시합니다.

## 2. VPN(DNS) 처리

앱은 Android `VpnService` 를 사용해 기기의 DNS 질의만 가상 DNS 서버로 보내 확인합니다.

- 일반 인터넷 트래픽(웹, 앱 통신)은 VPN 을 통과하지 않으며 앱이 읽거나 저장하지 않습니다.
- HTTPS 콘텐츠를 복호화하지 않습니다.
- DNS 질의는 기본적으로 기기의 시스템 DNS 로 전달되며, 사용자가 DoH/DoT 를 선택하면
  선택한 제공자에게 암호화되어 전달됩니다.
- VPN 은 사용자가 직접 켜고 끄며, 사용자가 중지한 VPN 을 앱이 임의로 다시 시작하지 않습니다.

## 3. 권한 사용 목적

- `INTERNET`, `ACCESS_NETWORK_STATE`: DNS 전달 및 보안 DB 업데이트
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `POST_NOTIFICATIONS`: VPN 상태 유지 및 알림
- `QUERY_ALL_PACKAGES`: 설치 앱 검사(핵심 기능). 검사 결과는 기기 밖으로 나가지 않습니다.

## 4. 보관 및 삭제

- 차단 기록: 기본 30일(설정에서 1~365일 변경 가능) 후 자동 삭제
- 검사 결과: 사용자가 "검사·차단 기록 삭제" 로 즉시 삭제 가능
- 앱 삭제 시 기기 내부 데이터는 함께 삭제됩니다.

## 5. 제3자 제공

앱은 사용자의 데이터를 판매하거나 제3자에게 제공하지 않습니다. 다만 다음의 경우
네트워크 요청이 발생합니다.

- 보안 DB/필터 업데이트: 설정된 HTTPS 업데이트 서버에 매니페스트와 페이로드를 요청
- DoH/DoT 사용 시: 사용자가 선택한 DNS 제공자에게 DNS 질의 전달

## 6. 오픈소스

사용한 오픈소스 목록과 라이선스는 `docs/THIRD_PARTY_LICENSES.md` 및 앱 내
"오픈소스 라이선스" 화면에서 확인할 수 있습니다.

## 7. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 별도로 수집하지 않습니다.
